First bytes


          
The 26-byte signature: maker, console, file type and format revision. The session
            structure counts and the offset table follow; see the header.

        

        

          
Most frequent names

          
Length-prefixed strings, counted. A channel name is stored once per processing
            block, so a channel with 13 blocks shows 14 times in the live state alone.

          
    
        
    
      
    
      
    
    
    

    
    
      
    
    
    

    
    
      
    
      
    
        Raw decode output (JSON)
        
    
      
    
      
    Decoded with the section map in Format: header, live state, snapshots, fader
        banks, macros, presets, sockets. Names and values are read straight from the file; what each parameter
        means is tagged reasoned in the notes until it is checked in the offline software.

    The .drawio files open in draw.io (desktop or app.diagrams.net). The mix structure
        is one page: sockets, input channels, groups, auxes, matrix. Routing is drawn in ink, aux sends in red with
        their level. Prune it there; a hundred channels into thirty-six auxes is a dense drawing.
